# Synthetic demo data policy

The production loopback demo ships only hand-authored synthetic JSON fixtures and SHA-256 summaries. It does not bundle nuScenes, OpenLane, or Waymo raw data, images, point clouds, archives, or absolute source paths. Mutable review history, exports, and browser evidence stay in the browser workspace/evidence output rather than a data root.

OpenLane data is subject to the Waymo Dataset License Agreement and CC BY-NC-SA terms. It is **non-commercial only**; a commercial user must not treat this demo as permission to acquire, redistribute, or use OpenLane raw data.
